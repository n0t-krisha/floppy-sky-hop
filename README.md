# Sky Jumper

A tiny, pixelated 3D cloud-hopping game about a little bunny, sky treasures, and a carrot-top picnic.

## Play

Run `npm install` and `npm run dev`, then open the local URL Vite prints. Move with `WASD` or the arrow keys, jump with `Space`, and hold `Shift` to run faster. Drag with the left mouse button to look around. Use the top-bar pause and sound buttons to pause, continue, mute, or unmute. The background track is played from its YouTube embed; an internet connection is required. Touch controls appear on phones and tablets. Open the journal in the upper-right corner to see discoveries.

Stars, blossoms, a feather, and a rainbow pin fill out the scrapbook. Honey slows the bunny for five seconds; the yarn ball circles its larger cloud, and a yarn tumble pauses movement for three. Reach the carrot pile to finish the trail.

## Publish with GitHub Pages

1. Make the repository public in **Settings → General → Danger Zone → Change repository visibility**.
2. In **Settings → Pages**, choose **GitHub Actions** as the build and deployment source.
3. Open **Actions → Deploy GitHub Pages → Run workflow**.

The published site URL is `https://n0t-krisha.github.io/floppy-sky-hop/`.
